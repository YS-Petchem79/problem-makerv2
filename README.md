# 📚 전공 특화 문제집 메이커

고등 물리학 실제 문제로 학습 보조 서비스를 체험할 수 있는 **스마트 학습 플랫폼**입니다.

## 🎯 핵심 기능

### 1️⃣ 문제 풀이 및 학습
- **다양한 문제 유형**: 객관식, 단답형, 계산형 포함
- **난이도별 선택**: 하, 중, 상 중 원하는 난이도 선택
- **단계별 힌트**: 문제 풀이 시 진행 방식에 따라 힌트 제공
- **상세 해설**: 각 문제마다 풀이 과정과 개념 설명 포함

### 2️⃣ 오답노트 시스템
- **자동 저장**: 틀린 문제가 자동으로 오답노트에 저장
- **필터링**: 상태(미해결/복습 완료), 난이도, 개념별로 필터링
- **복습 기능**: 오답을 다시 풀고 진도 추적
- **취약 개념 분석**: 가장 자주 틀리는 개념 확인

### 3️⃣ 학습 통계 대시보드
- **종합 통계**: 정답률, 평균 풀이 시간, 연속 학습일
- **성과 점수**: 0~100점 학습 성취도
- **날짜별 추이**: 학습 성과 그래프
- **유형/난이도별 분석**: 각 문제 유형과 난이도별 정답률
- **개념별 숚달도**: 각 개념의 학습 진도 확인

## 🚀 빠른 시작

### 온라인에서 (GitHub Pages)
GitHub Pages로 배포되어 있습니다. 저장소의 Settings에서 Pages 링크를 확인하세요.

### 로컬에서 실행

#### 방법 1: 브라우저에서 직접 열기
1. 저장소를 다운로드합니다
2. `index.html`을 웹 브라우저에서 엽니다
3. 문제 풀이 시작!

#### 방법 2: 로컬 웹 서버 실행 (권장)

**Python 사용** (3.x 이상)
```bash
python -m http.server 8000
```

**Node.js 사용**
```bash
npx http-server
```

**PHP 사용**
```bash
php -S localhost:8000
```

그 후 브라우저에서 `http://localhost:8000` 접속합니다.

## 🎓 포함된 문제 주제

**고등 물리학** (총 40개 문제)
- 직선운동: 5개
- 뉴턴의 운동법칙: 5개  
- 일과 에너지: 5개
- 열역학: 4개
- 파동: 4개
- 전기장: 4개
- 자기장: 4개
- 원자 구조: 4개
- 원운동 및 기타: 6개

**난이도**
- 쉬움 (하): 약 10개
- 중간 (중): 약 10개
- 어려움 (상): 약 20개

**문제 유형**
- 객관식 (50%)
- 단답형 (25%)
- 계산형 (25%)

## 💾 데이터 저장

모든 학습 데이터는 **로컬 브라우저**에만 저장됩니다:
- **localStorage**: 간단한 설정 정보
- **IndexedDB**: 풀이 기록, 오답 정보, 통계 데이터

브라우저 캐시를 삭제하면 데이터가 사라집니다.
